# GTA 6 Live Takeover: Design

Date: 2026-11-17 | Size: small change | Status: awaiting approval

## Intent
Celebrate the GTA 6 early gameplay stream like a global holiday. When a watched channel is **live** with a title that mentions GTA 6, the Windows app's "live now" indicators turn Miami Vice purple.

## Goals
- Live channel whose `StreamTitle` matches GTA 6 turns purple in every live indicator:
  - channel row: avatar ring, `LIVE` badge, "Live for..." text
  - popover: top `N LIVE` pill and `LIVE NOW (N)` header
  - system tray: purple icon, tooltip `VRemind (Live now - GTA 6)`
- Detection is client-side only.

## Non-goals / anti-goals
- **No changes to `VRemindCore`, `VRemindCoreCLI`, or `vremind-core.exe`.** The CLI JSON contract is untouched.
- Upcoming streams do not trigger it (live only). This is my call.
- The macOS app under `VRemind/` is untouched.
- Must not break the existing birthday/debut/anniversary celebration behavior when no GTA 6 stream is live.

## Constraints
- The only title data available is `CliChannelItem.StreamTitle`, which the CLI already supplies.
- The UI uses `x:Bind` with single-value converters in `UiConverters.cs`. Follow that pattern.
- `RainbowGradientProvider` drives animation through `UpdateCelebrationAnimationState` in `PopoverView.xaml.cs`.

## Approaches
1. **First-class `"gta6"` visual kind in the Windows layer. (Chosen.)** Detect in `VRemindWin.Core`, extend `EffectiveVisualKind` and `PopoverViewModel`, add converter mappings and a purple tray icon. Leaves CLI state untouched, fits the existing binding pattern, and is easy to unit-test.
2. **Rewrite incoming state in `StreamMonitorCoordinator.ProjectIncomingState`**, setting `IsCelebration` and `CelebrationType = "gta6"`. Rejected: the XAML binds headers to booleans, so `PopoverViewModel` and the converters need changes anyway, and mutating CLI DTOs makes state harder to debug.

## Design

### Detection
- New static `Gta6Detector.IsMatch(string? title)` in `VRemindWin.Core/Services`.
- Case-insensitive, word-boundary regex. Variants: `GTA 6`, `GTA6`, `GTA VI`, `GTAVI`, `Grand Theft Auto 6`, `Grand Theft Auto VI`. It allows flexible whitespace and a hyphen between "GTA" and the numeral.
- Must not match `GTA 60`, `GTA 600`, or `GTA 5`.

### Model (`CliContracts.cs`)
- `CliChannelItem.IsGta6Live` = `IsLive && Gta6Detector.IsMatch(StreamTitle)`.
- `EffectiveVisualKind` order: `"gta6"` if `IsGta6Live`, else `"celebration"` if `IsCelebration`, else `StatusKind`.
- `StatusBadgeText` stays `LIVE`. `ShowStatusBadge` is unchanged because the item is live.
- No new JSON properties, so deserialization is unaffected.

### ViewModel (`PopoverViewModel.cs`)
- `IsLiveSectionGta6` = any live channel with `IsGta6Live`.
- `LiveHeaderVisualKind`: `"gta6"` if `IsLiveSectionGta6`, else `"celebration"` if `IsLiveSectionCelebrating`, else `"live"`.
- `IsPopoverCelebrating` = coordinator value OR `IsLiveSectionGta6`. This triggers confetti. Reduce-motion behavior is unchanged.
- Raise change notifications for the new properties in `RaiseStatePropertiesChanged`.

### Brushes (`UiConverters.cs`)
- A shared Miami Vice purple `LinearGradientBrush`, electric violet `#8B5CF6` to neon magenta `#D946EF`, **static** (not animated).
- Add a `"gta6"` case to `StatusKindToTimeBrushConverter`, `StatusKindToAvatarRingBrushConverter`, and `StatusKindToBadgeBrushConverter`.
- Replace the bool-based `CelebrationBadgeBrushConverter` and `CelebrationLiveHeaderBrushConverter` bindings in `PopoverView.xaml` with string-kind equivalents that bind to `LiveHeaderVisualKind`. Keep the old converters if still used elsewhere.
- `PopoverView.xaml.cs`: include `IsLiveSectionGta6` in the property-change filter. Rainbow animation is not required for GTA 6 alone.

### Tray (`TrayIconService.cs`, `App.xaml.cs`)
- New `Assets/tray-gta6.ico`, 16x16 and 32x32 at 32bpp like `tray-live.ico`. It is generated by recoloring `tray-live.ico`: the dominant `#EF4444` becomes purple and the shading shades map proportionally. Add it to `VRemindWin.csproj` as content, copied like the other icons.
- Replace `SetLiveState(bool)` with a three-state `SetTrayState(Normal | Live | Gta6Live)`. The tooltip for GTA 6 is `VRemind (Live now - GTA 6)`.
- `UpdateTrayLiveState` in `App.xaml.cs` picks the state from `CurrentState.Sections.Live`.
- Dispose the extra icon handle.

### Tests (`VRemindWin.Tests`)
- `Gta6Detector`: every variant matches, case and spacing variants match, `GTA 5`, `GTA 60`, and empty or null titles do not match.
- `CliChannelItem`: live+match gives `"gta6"`, upcoming+match does not, GTA 6 takes priority over `IsCelebration`.
- `PopoverViewModel`: `LiveHeaderVisualKind` precedence and `IsPopoverCelebrating`.

## My calls (not yet confirmed by you)
- **Priority:** GTA 6 beats the rainbow celebration on shared indicators, and it is static rather than animated.
- **Confetti:** a live GTA 6 stream triggers popover confetti.
- **Live only:** upcoming GTA 6 streams are not highlighted.
- **Palette:** `#8B5CF6` to `#D946EF`. This is the Miami Vice variant you approved in direction, not the earlier Purple-500/600 pair.
